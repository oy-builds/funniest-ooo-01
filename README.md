# The Office Quit First

A make.fun entry for "The Funniest Out-of-Office": one funny single-line
out-of-office auto-reply.

`main.ts` (Node 22, standard library only) writes the reply to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> I'm out of office — the office quit first, so I'm replying from the beach it ran off to. Emergencies go to the tide.

Run it with `node main.ts`.
